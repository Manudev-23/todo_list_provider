# Todo List Provider

Aplicativo de gerenciamento de tarefas desenvolvido com Flutter.

---

## Sobre o projeto

Este projeto foi desenvolvido com foco em estudos de:

- Arquitetura Flutter
- Provider
- SQLite
- Organização modular
- Boas práticas

---

## Tecnologias utilizadas

- Flutter
- Dart
- Provider
- SQLite

---

## Funcionalidades

- Login
- Cadastro de usuário
- Lista de tarefas
- Categorias
- Subtarefas
- Persistência local de dados

---

## Arquitetura

O projeto foi organizado utilizando:

- Controllers
- Services
- Repositories
- Providers
- Modularização de features

---

## Estrutura do projeto

lib/
